# foliopage Brand Design Document

## 1. Brand Overview

### Brand Name
- `foliopage`

### Brand Purpose
- Help students and early-career builders present themselves clearly with one professional link.

### Brand Promise
- `Less profile noise. More interview callbacks.`

### Positioning
- A resume-first link-in-bio platform built for internships, early careers, and portfolio-driven applications.
- Complement to LinkedIn, not a replacement.

## 2. Mission, Vision, Values

### Mission
- Enable any student to build and share a polished, recruiter-friendly career page in minutes.

### Vision
- Become the default career link format for students and early-career professionals.

### Core Values
- Clarity over clutter
- Structure over decoration
- Progress over perfection
- Professional but approachable

## 3. Audience

### Primary Audience
- Students (18-24), internship seekers, early-career candidates.
- Profile traits:
- Has a resume PDF
- Has 2-5 projects
- Wants better presentation without building a custom site

### Secondary Audience
- Recruiters and hiring teams who need fast candidate evaluation.

## 4. Brand Personality

### Personality Traits
- Confident
- Practical
- Direct
- Energetic
- Career-ambitious

### Tone Sliders
- Professional: `High`
- Playful: `Medium`
- Technical: `Medium`
- Formal: `Medium-low`
- Friendly: `High`

### Voice Rules
- Use short, clear sentences.
- Lead with outcomes.
- Avoid corporate fluff and vague hype.
- Prefer verbs: `build`, `share`, `launch`, `apply`, `get hired`.

### Messaging Style
- Good: `Build one clean link for every application.`
- Avoid: `Elevate your digital identity through next-gen career storytelling.`

## 5. Messaging Framework

### Primary Value Proposition
- `A link in bio built for your career.`

### Supporting Messages
- Resume-first profile format
- Fast setup (`~10 minutes`)
- Recruiter-friendly structure
- One link for applications, referrals, and DMs

### Tagline Options
- `One link. Real career signal.`
- `Resume-first. Callback-ready.`
- `Built for student careers.`

## 6. Visual Identity

### Core Brand Color
- Primary accent: `#f04939`

### Extended Palette (from current landing direction)
- Lime section: `#c8ea2d`
- Blue section: `#2f63c9`
- Burgundy section: `#8a0b24`
- Sage section: `#d8dac7`
- Purple CTA section: `#5b2c86`
- Base background: `#f2eee3`
- Text / ink: `#161616`

### Color Usage Rules
- Use `#f04939` for primary CTA, key highlights, and action emphasis.
- Use one major section color at a time.
- Keep text/background contrast high for readability.
- Avoid random new accents without updating this document.

### Suggested Token Mapping
- `--brand-primary: #f04939`
- `--brand-primary-hover: #d73d2e`
- `--bg-base: #f2eee3`
- `--text-base: #161616`
- `--surface-light: #ffffff`
- `--surface-tint: #f7f5ee`

## 7. Typography

### Font Stack
- Primary: `Space Grotesk`
- Supporting mono/data: `IBM Plex Mono`
- Fallback: `Segoe UI`, system sans-serif

### Type Roles
- Display headlines: Space Grotesk, bold
- Body: Space Grotesk, regular/medium
- Numeric/stat/metric text: IBM Plex Mono or tabular numeric styling

### Typography Guidelines
- Prioritize bold, high-impact headers.
- Keep body copy compact and readable.
- Use `text-balance` for headings and `text-pretty` for paragraphs.
- Use `tabular-nums` for metrics and pricing.

## 8. Layout and Component Language

### Layout Direction
- Editorial and band-based sections.
- Strong horizontal flow and clear visual rhythm.
- Prefer sharp edges or low-radius surfaces over heavy rounded-card repetition.

### Component Shape Rules
- Primary panels: low radius or square corners.
- CTA buttons: pill or semi-rounded for contrast.
- Avoid stacking many identical rounded cards.

### Spacing System
- 8px scale base.
- Larger section spacing for campaign/landing pages.
- Keep scan paths obvious: headline -> proof -> CTA.

## 9. Iconography and Imagery

### Icon Style
- Use `Phosphor` icon set (consistent stroke style).
- Icons should support hierarchy, not decorate randomly.

### Imagery Style
- Career-focused mockups and profile snapshots.
- High-contrast, simple compositions.
- Avoid generic stock-photo dependency.

## 10. Motion and Interaction

### Motion Principle
- Functional, quick, minimal.

### Rules
- Prefer no animation by default.
- If used, animate only opacity/transform.
- Keep interaction feedback snappy (`<=200ms`).
- Avoid large blur/glow-heavy animated backgrounds.

## 11. Accessibility Standards

### Minimum Requirements
- WCAG AA contrast for text and controls.
- Visible keyboard focus states.
- Semantic heading structure.
- Descriptive link/button text.
- Avoid icon-only controls without labels.

### Content Accessibility
- Keep copy concise and scannable.
- Avoid long dense blocks on landing pages.

## 12. Brand Applications

### Product UI
- Resume-first hierarchy.
- Strong CTA presence.
- Clear sections: Resume, Projects, Skills, Contact.

### Marketing Pages
- Outcome-focused hero.
- Proof blocks (metrics, testimonials).
- Repeated CTA opportunities.

### Social and Community
- Consistent use of brand red (`#f04939`) as action color.
- Tone: practical, career-driven, optimistic.
